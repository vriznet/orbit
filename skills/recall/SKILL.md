# 기억 찾기 (recall)

찾을 것: $ARGUMENTS

(인자가 비었으면 지금 대화에서 무엇을 기억해 내야 하는지 한 줄로 정해 그것을 찾는다.)

## 먼저 확인

이 스킬은 orbit이 설치된 저장소에서만 쓴다. 저장소 루트에 `.claude/orbit-manifest.json`이 없으면 "이 저장소에는 orbit이 설치되어 있지 않습니다(`/orbit:setup`으로 설치)"라고 알리고 멈춘다.

## 절차

1. **빠른 찾기**: 먼저 직접 돌린다.
   ```bash
   node scripts/memory.mjs search '<낱말 두세 개>'
   ```
   목록에서 답이 분명하면 `node scripts/memory.mjs show <번호>`로 한두 개만 열어 확인하고 바로 답한다.
2. **깊은 찾기**: 아래 중 하나면 `recall-searcher` 서브에이전트에 맡긴다(Agent 도구, `subagent_type: recall-searcher`).
   - 목록이 비었거나 맞는 것이 없다.
   - 질문이 바꿔 말한 것이거나 암묵적이다("그 방식", "아까 버린 거").
   - 여러 번 바뀐 결정이라 흐름을 따라가야 한다.

   위임 글에는 찾을 것, 이미 해 본 낱말, 필요한 답의 모양(결론·이유·날짜)을 적는다. 서브에이전트는 답과 출처 목록만 돌려준다.
3. **답하기**: 결론을 먼저 말하고 출처(번호·파일·날짜)를 붙인다. 옛 결정이 나중에 바뀌었으면 최신 것을 답으로 하고 바뀐 사실을 함께 적는다. 찾지 못했으면 그렇게 말하고 추측으로 채우지 않는다.

기억을 지워 달라는 요청은 이 스킬이 아니라 `/orbit:forget`으로 한다.
