# 의사결정 로그 (ADR)

> 결정 1건 = 파일 1개. **확정된 파일은 수정하지 않는다.** 바꿀 일이 생기면 새 결정을 만들고, 옛 파일에 `> ⚠️ <새 ADR>으로 대체됨` 링크만 추가한다.
> 왜 이렇게? 결정이 어떻게 바뀌었는지의 사슬을 남기기 위해서다. 지금 결정이 틀렸을 수 있다는 가정 하에, 나중에 "결정이 문제였나, 실행이 문제였나"를 되짚는다.
> 새 결정은 파일명 `D-슬러그-YYMMDD-HHMMSS.md`(예: `D-원장ID형식-260807-193512.md`)로 파일을 추가하고 아래 표에 한 줄 넣는다. 슬러그가 무슨 결정인지 먼저 알려주고, 일시가 병렬 세션 간 번호 충돌을 없앤다. 기존 순번 ID가 있으면 그대로 둔다 — 표의 행 순서가 선후를 담는다.
