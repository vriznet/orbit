# Backlog — 조건부·미착수 작업

> "언제(트리거) 무엇을" 형식으로 쌓는다. 여기 항목은 [tasks.md](./tasks.md)의 Waiting 항목과 짝을 이룬다 — 조건부 작업은 tasks에 Waiting으로도 등록하고(scripts/tasks.mjs, `--wait`에 트리거) 그 task ID(`T-슬러그-YYMMDD-HHMMSS`)를 여기 함께 적어 연결한다.
> 새 단계·큰 작업을 시작하기 전, 여기서 트리거가 걸린 항목이 있는지 확인한다. 항목을 닫을 때는 짝이 되는 tasks 항목도 함께 정리한다(결과를 얻었으면 `done`, 트리거 자체가 사라졌으면 `drop --reason`).
