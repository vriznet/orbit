# 프로젝트 위키

> 프로젝트에서 여러 번 다시 쓸 지식을 연결해 보관한다. Obsidian 볼트 루트는 `{{DOCS_DIR}}/`다.

## 무엇을 남기는가

- 조사에서 확인한 사실과 출처
- 여러 작업에 적용할 개념과 원칙
- 도입을 검토하는 AI 시스템과 도구
- 실험의 가설, 방법, 결과, 해석
- 반복해서 사용할 절차와 구현 지식

## 운영 원칙

1. 대화 전문을 저장하지 않는다. 다시 쓸 가치가 있는 지식만 짧게 정리한다.
2. 확인한 사실, 출처의 주장, 우리의 추정을 구분한다.
3. 기존 노트와 같은 주제면 새 파일을 만들기 전에 기존 노트를 갱신한다.
4. 본문에서 다른 문서를 처음 의미 있게 언급할 때 위키 링크를 사용한다.
5. 관련성이 불확실하면 억지로 연결하지 않는다.
6. 위키 노트는 지식이 바뀌면 갱신할 수 있다. 확정된 ADR의 불변 규칙은 그대로 유지한다.
