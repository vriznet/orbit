# 잊어 줘 (/forget)

지울 문구: $ARGUMENTS

삭제는 되돌릴 수 없다. 그래서 이 스킬은 사용자가 `/forget`으로 직접 부를 때만 동작한다. 대화 중에 "잊어 줘"라는 말이 나와도 스스로 지우지 말고 `/forget <문구>`를 안내한다.
결정: D-잊어줘-슬래시명령-260926-131349.

## 절차

1. **문구 확인**: 문구가 비었거나 한 글자면 멈추고, 무엇을 지울지 한 줄로 묻는다.
2. **미리 보기**: 저장소 루트에서 아래를 실행한다. 문구는 셸 따옴표를 깨지 않게 작은따옴표로 감싸고, 안의 작은따옴표는 `'\''`로 바꾼다.
   ```bash
   node scripts/memory.mjs forget '<문구>'
   ```
   아직 아무것도 지우지 않는다. 결과에서 세 가지를 읽는다.
   - orbit 사본: 대화 글 사본·도구 색인에서 지울 줄 수
   - 컴팩션 상태 파일·요약: 지울 파일
   - git이 추적하는 원장: 문구가 든 파일:줄
3. **확인 받기**: 미리 보기를 표(곳 | 찾은 수 | 처리)로 짧게 보여 주고 AskUserQuestion으로 묻는다.
   - "지우기": orbit 사본과 컴팩션 파일을 지우고, 원장의 해당 줄에서 문구를 지운다.
   - "사본만 지우기": orbit 사본과 컴팩션 파일만 지우고 원장은 그대로 둔다.
   - "취소": 아무것도 하지 않는다.
   찾은 것이 하나도 없으면 묻지 않고 "찾은 기록이 없다"고 알린 뒤 끝낸다.
4. **지우기**: 사용자가 고른 대로 한다.
   - orbit 사본·컴팩션 파일: `node scripts/memory.mjs forget '<문구>' --apply`
   - 원장(worklog·ADR·위키·할일 등): 각 파일:줄에서 문구를 `[지움]`으로 바꾼다(Edit). 문장이 문구 때문에만 있던 줄이면 줄째 지운다. worklog의 "덧붙이기만" 규칙보다 이 요청이 앞선다. `tasks.md`처럼 스크립트가 만드는 파일은 원본(`tasks.json`)을 함께 고친다.
   - 커밋은 하지 않는다. 사용자가 요청할 때만 한다.
5. **끝 보고**: 지운 것(곳별 수)과 함께 orbit이 지우지 못하는 곳을 알린다.
   - git 이력: 원장을 고쳐도 옛 커밋에는 남는다. 이력까지 지울지는 따로 정한다.
   - Claude Code 원본 세션 기록(`~/.claude/projects/…`의 jsonl)과 자동 기억(MEMORY.md)
   - 지금 대화의 문맥: 컴팩션이나 새 세션 전까지는 남아 있다.
