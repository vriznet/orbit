# Orbit config

바꿀 것: $ARGUMENTS

설치할 때 정한 것과 조절 스위치를 나중에 다시 바꾸는 스킬이다. setup처럼 **고르는 화면(`AskUserQuestion`)으로 묻고**, 고른 값을 `config.mjs`로 적용한다. 지금 설정을 길게 늘어놓는 것으로 끝내지 않는다.

## 전제

- 대상 저장소에 `.claude/orbit-manifest.json`이 있어야 한다. 없으면 "먼저 orbit:setup으로 설치하세요"라고 알리고 멈춘다.
- 현재 디렉터리가 대상 Git 저장소 루트인지 확인한다.

## 절차

1. 지금 값을 조용히 읽는다. 이 출력은 선택지를 만드는 재료다. 사용자에게 통째로 보여 주지 않는다.

   ```bash
   node "${CLAUDE_SKILL_DIR}/../setup/scripts/config.mjs" show --repo "$PWD" --json
   ```

2. **무엇을 바꿀지 고르게 한다.** `AskUserQuestion`을 한 질문만 담아 부른다. 선택지는 아래 "묶음" 표의 묶음이다. 인자(`$ARGUMENTS`)가 어느 설정인지 분명하게 가리키면 이 단계와 3단계를 건너뛴다.
3. **그 묶음 안에서 설정 하나를 고르게 한다.** 선택지 라벨은 설정의 쉬운 이름, 설명에는 **지금 값**과 무엇을 하는 설정인지를 적는다. 묶음에 설정이 하나뿐이면 이 단계를 건너뛴다.
4. **값을 고르게 한다.** 선택지는 아래 "값 선택지" 표의 실제 값이다. 지금 값인 선택지는 설명에 "지금 값"이라고 적는다. 표에 없는 값은 사용자가 질문 화면의 `Type something`에 직접 적는다.
5. 적용한다. 한 번에 하나씩 부른다.

   ```bash
   node "${CLAUDE_SKILL_DIR}/../setup/scripts/config.mjs" set --repo "$PWD" <이름> <값> [옵션…]
   node "${CLAUDE_SKILL_DIR}/../setup/scripts/config.mjs" unset --repo "$PWD" <이름>   # 기본값으로
   ```

   명령이 값을 거부하면(종료 코드가 0이 아님) 이유를 한 줄로 알리고 4단계의 값 질문만 다시 한다.
6. 바뀐 것을 한두 줄로 알린다(무엇이 무엇에서 무엇으로, 언제부터 적용되는지). 이어서 `AskUserQuestion`으로 더 바꿀지 묻는다: `다른 설정도 바꾸기` / `여기서 끝내기`. 더 바꾸면 2단계로 돌아간다.

인자가 있을 때: 인자가 설정과 값까지 말하면("발견 칸 알림 기준 20으로") 바로 5단계로 간다. 설정만 말하면 4단계부터 묻는다. 어느 설정인지 분명하지 않으면 2단계부터 묻는다.

### AskUserQuestion 호출 형식 (모든 질문 공통)

아래 필수 필드를 빠짐없이 채운다. 하나라도 빠지면 `Invalid tool parameters`로 호출 자체가 실패한다.

- `question`: 완전한 문장으로 끝나는 질문.
- `header`: 12자 이내의 짧은 라벨(예: `바꿀 것`, `알림 기준`).
- `options`: 2~4개. 선택지마다 `label`(실제로 선택될 값이나 행동)과 `description`(뜻, 지금 값인지) 둘 다 필수다.
- `multiSelect`: `false`를 명시한다.

- 한 번 호출에 질문 하나만 담는다. 앞 답을 받은 뒤 다음 질문을 부른다.
- 선택지에 `직접 입력`, `기타`, `Other`, `Type something` 같은 가짜 항목을 만들지 않는다. 그런 항목을 누르면 그 문구 자체가 답이 된다. 자유 입력은 Claude Code가 질문 화면에 자동으로 붙이는 `Type something` 칸을 쓴다.
- 사용자가 `Type something`에 적은 글은 선택지와 달라도 실제 답으로 받는다. 빈 값이거나 취소면 아무것도 바꾸지 않고 끝낸다.
- 값 선택지의 라벨에는 `추천값` 같은 설명이 아니라 실제 값 자체를 넣는다.
- 호출이 `Invalid tool parameters`로 실패하면 필수 필드를 점검해 다시 부른다. 그래도 실패하면 그 질문만 평문으로 묻는다.

## 묶음

| 묶음(선택지 라벨) | 들어 있는 설정 |
|---|---|
| 조절 스위치 | `found-min-tools`, `read-outline-min-lines`, `compact-worklog`, `again`, `verify-nudge`, `agent-policy` |
| 선택 모듈 켜기 | `codex`, `reviewers` (이미 켜진 것은 설명에 "이미 켜짐"이라고 적는다. 둘 다 켜져 있으면 이 묶음을 선택지에서 뺀다) |

## 값 선택지

| 설정 | 쉬운 이름 | 선택지(라벨) | 자유 입력 |
|---|---|---|---|
| `found-min-tools` | '발견' 칸 알림 기준 | `10`(기본), `5`, `20`, `0`(끔) | 0 이상의 수 |
| `read-outline-min-lines` | 큰 파일 개요 안내 기준 | `300`(기본), `200`, `500`, `0`(끔) | 0 이상의 수 |
| `compact-worklog` | 컴팩션 직후 worklog 다시 넣기 | `on`(기본), `off` | 없음 |
| `again` | '다시'(번복·재발) 감지와 주제 흐름 넣기 | `on`(기본), `off` | 없음 |
| `verify-nudge` | '고쳤다'인데 확인 칸이 없을 때 알림 | `on`(기본), `off` | 없음 |
| `agent-policy` | general-purpose·fork 위임 막기 | `off`(기본), `on` | 없음 |
| `codex` | Codex와 턴제 협업 모듈 | `켜기`, `그대로 두기` | 없음 |
| `reviewers` | 리뷰어 에이전트 5종 | `켜기`, `그대로 두기` | 없음 |

- `(기본)`인 값을 고르면 `set` 대신 `unset`을 불러 설정 파일에서 그 줄을 지운다.
- `켜기`는 `set <이름> on`으로 부른다. `그대로 두기`는 아무것도 부르지 않는다.
- 조절 스위치는 저장소의 `.claude/settings.local.json` `env`에 적힌다. 개인용 파일이라 커밋되지 않고 update가 건드리지 않는다.
- 모듈을 켜면 설치기가 저장소 파일을 바꾼다. 바뀐 파일을 알려 주고, 커밋은 사용자가 요청할 때만 한다.
- 모듈 끄기는 지원하지 않는다. 사용자가 끄기를 원하면 그렇게 알린다.

## 원칙

- 위 표에 없는 것은 바꾸지 않는다. 명령이 "모르는 설정"이라고 답하면 그대로 전한다.
- 슬러그·문서 폴더 이름·표시 이름은 설치 뒤에 바꾸지 않는다(파일 이름과 원장이 그 값에 묶여 있다).
- 설정 파일을 손으로 고치지 않고 명령으로만 바꾼다.
- 사용자 화면에는 `set`·`unset` 같은 내부 명령 이름이나 원시 JSON을 쓰지 않는다. 사용자가 "지금 설정 보여 줘"라고 따로 요청할 때만 `show`(--json 없이) 출력을 쉬운 말로 정리해 보여 준다.
